# Downloadable brand files

Anything in this folder appears on the site under **Downloads**, grouped by
subfolder. Drop a file in, commit, and Vercel republishes within a minute — the
build script scans this folder, so there is no index to maintain.

```
assets/
  logo/     Logo lockups and icons (SVG)
  fonts/    Instrument Sans, Inter, Inter Tight
  decks/    PowerPoint and Keynote templates
  social/   LinkedIn banners and post templates
  print/    Anything meant for print
```

Subfolder names become section headings, so name them the way you want them read.
Files sit at any depth; only the first folder decides the group.

`README.md` files and dotfiles are skipped.

**This repository is public.** Every file here is downloadable by anyone with the
URL. Keep sales decks, pricing sheets, customer data and unreleased work out of it.
