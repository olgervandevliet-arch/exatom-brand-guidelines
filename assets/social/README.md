# Social media assets

The finished, real files used on the Social media guide — not generated
mockups. Drop a new one in here (or replace one of these) and it appears on
the Downloads page under "Social templates" automatically; update the `src`
in `src/Social.src.html` if the filename changes.

- `linkedin-banner.jpg` — the live LinkedIn company page banner (4440x1056).
- `webinar-banner.jpg` — the webinar promo banner template (4096x1048).
- `profile-icon.png` / `.jpg` — the flat square icon used as the profile
  picture on every account (LinkedIn, and any future channel).
